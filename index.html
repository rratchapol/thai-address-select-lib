GETTING STARTED

ติดตั้ง thai-address-select ด้วย npm

ติดตั้งแพ็กเกจ แล้วนำเข้าในแอปฝั่ง browser ที่ใช้ bundler เช่น Vite 

npm install thai-address-select
ใช้ bundler เพื่อจัดการ ES modules และ JSON

source นำเข้าฐานข้อมูล JSON โดยตรง และ entry point มี import ที่ไม่ระบุนามสกุล จึงไม่ควรเปิดไฟล์ HTML ผ่าน file:// หรือ import ไฟล์ใน dist ตรง ๆ ใน browser โดยไม่มี bundler

ต้องการรันเว็บเอกสารนี้บนเครื่อง?

ใช้ Node.js 22.12+ หรือ 24+ สำหรับเครื่องมือเว็บเอกสาร จากโฟลเดอร์ repository รัน:

npm run docs:build สร้างเว็บใน docs-dist/ และ npm run docs:preview เปิดดูผล build ส่วน npm run build ยังใช้ build ไลบรารีเหมือนเดิม

Methods

getValue()

คืน { province?, district?, subDistrict?, zip_code? } เป็น string หรือ undefined รหัสไปรษณีย์ได้เมื่อเลือกครบและพบในข้อมูล

setValue(value)

เติมค่าตาม ThaiAddressValue โดยไม่ส่ง event ใช้ setValue({}) เพื่อล้างทั้งฟอร์ม ไม่ใช่การ merge ค่าเดิม

destroy()

ถอด listener ของไลบรารีออกจาก select ทั้งสามช่อง ไม่ลบ DOM และไม่ถอด listener ที่คุณเพิ่มเองบน instance

Events · CustomEvent.detail

Event ส่งเมื่อ detail
provinceChange ผู้ใช้เปลี่ยนจังหวัด { province }
districtChange ผู้ใช้เปลี่ยนอำเภอ { province, district }
subDistrictChange ผู้ใช้เปลี่ยนตำบล { province, district, subDistrict }
selectChange เลือกครบสามช่อง { province, district, subDistrict, zip_code }

UNDER THE HOOD

เล็กพอที่จะอ่านโค้ดตามได้

หน้าที่หลักแบ่งเป็นสามส่วน: ข้อมูล → ฟังก์ชันกรอง → ตัวควบคุม dropdown

JSONฐานข้อมูลที่อยู่thai-address.json
→
TSค้นหาและกรองfilterAddress.ts
→
DOMเชื่อม dropdownThaiAddressSelect.ts

สิ่งที่ควรรู้จากการอ่านโปรเจค

  • ข้อมูลอยู่ใน bundle: JSON ต้นฉบับมีขนาดประมาณ 3.43 MB ก่อน minify และบีบอัด ไม่มีการเรียก API ที่อยู่ภายนอกตอนเลือก dropdown
  • จัดการ DOM โดยตรง: ใช้ document, EventTarget และ CustomEvent จึงควรสร้าง instance หลัง mount บน client
  • แยก build เว็บกับไลบรารี: tsc สร้าง JavaScript และ declarations ใน dist/; Vite bundle เว็บเอกสารไปที่ docs-dist/
  • ตรวจ packaging ก่อนนำไปเผยแพร่: package.json ยังระบุ dependency ชื่อเดียวกับแพ็กเกจตัวเอง และชี้ require ไปไฟล์ ESM จึงไม่รับรองการใช้ผ่าน CommonJS จากเว็บเอกสารนี้
  • ขอบเขตของข้อมูล: จำนวนบนหน้านี้นับรายการจากไฟล์จริงใน repository ไม่ใช่ข้อมูลเขตการปกครองล่าสุดที่ยืนยันโดยหน่วยงานภายนอก

แหล่งอ้างอิงของเอกสารและข้อมูล

พฤติกรรม API ตรวจจากโค้ดโดยตรง คุณตรวจสอบหรือแจ้งข้อมูลที่ควรแก้ได้จากแหล่งต่อไปนี้:

  • แพ็กเกจ thai-address-select บน npm — เวอร์ชันที่เผยแพร่และคำสั่งติดตั้ง
  • ThaiAddressSelect.ts — การเลือกที่อยู่ ค่าเริ่มต้น และ events
  • filterAddress.ts — ฟังก์ชันค้นหาจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์
  • thai-address.json — snapshot ที่ใช้คำนวณจำนวนรายการบนหน้านี้
  • แจ้งปัญหาหรือเสนอแก้ไขเอกสาร
A FEW USEFUL ANSWERS

คำถามที่พบบ่อยเกี่ยวกับ thai-address-select

ต้องใช้ API ภายนอกเพื่อค้นหารหัสไปรษณีย์ไหม?

ไม่ต้องเรียก API ที่อยู่ภายนอกตอนเลือกฟอร์ม เพราะ thai-address-select นำเข้าข้อมูลจังหวัด อำเภอ ตำบล และรหัสไปรษณีย์จาก JSON ในแพ็กเกจ ผ่าน bundler ของแอป ข้อมูลนี้ไม่ sync อัตโนมัติ

เปลี่ยนจังหวัดแล้วรหัสไปรษณีย์เก่ายังแสดงอยู่?

selectChange จะไม่ส่งเมื่อเลือกไม่ครบ ให้ฟัง provinceChange และ districtChange แล้วอ่าน getValue().zip_code ?? "" ใหม่ตามตัวอย่างเริ่มต้น

ทำไมเปิด index.html ตรง ๆ แล้วเดโมไม่ทำงาน?

เว็บนี้ต้องผ่าน Vite เพื่อแปลง TypeScript และ JSON ให้รัน npm install แล้ว npm run docs:dev จาก repository และเปิด URL ที่ terminal แสดง

ใช้กับ React หรือ Next.js ได้อย่างไร?

สร้าง instance ใน useEffect หลัง DOM พร้อม ใช้ dynamic import บน client และถอด listener พร้อมเรียก destroy() ตอน unmount ตัวอย่างในแท็บ React จัดการกรณี component ถูกถอดระหว่างโหลดด้วย

ตั้งค่าเริ่มต้นแล้วเลือกอำเภอหรือตำบลไม่ติด?

ชื่อต้องตรงกับข้อมูลและสัมพันธ์กันทั้งสามระดับ เรียก getDistricts(province) และ getSubDistricts(province, district) เพื่อดูชื่อจริง เช่นใช้ เขตบางรัก แทน บางรัก สำหรับอำเภอ

ปรับหน้าตาและปิดช่องที่ยังเลือกไม่ได้อย่างไร?

ไลบรารีใช้ select ของคุณ จึงแต่งด้วย CSS ได้ตามปกติ ส่วน disabled ต้องจัดการเองจากค่าปัจจุบัน เหมือนเดโมหน้านี้ที่เปิดช่องอำเภอหลังเลือกจังหวัด และเปิดช่องตำบลหลังเลือกอำเภอ

ข้อมูลจะอัปเดตให้อัตโนมัติไหม?

ไม่มีการ sync ข้อมูลภายนอก ข้อมูลผูกกับ JSON ในแพ็กเกจที่ติดตั้ง ควรตรวจสอบความเหมาะสมและความถูกต้องสำหรับงานของคุณก่อนใช้งานจริง
